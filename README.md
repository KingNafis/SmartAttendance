# UniMetrix

UniMetrix is a University Management System developed using the MERN Stack. The platform streamlines academic management by providing features for course administration, attendance tracking, and student performance monitoring.

## Features

- User Authentication and Authorization
- Course Management
- Student Management
- Attendance Tracking
- Marks and Result Management
- Responsive User Interface

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication

## Installation

### Clone the repository

git clone <repository-url>

### Install dependencies

Frontend:

cd client
npm install

Backend:

cd server
npm install

### Start the application

Frontend:

npm start

Backend:

npm run dev
